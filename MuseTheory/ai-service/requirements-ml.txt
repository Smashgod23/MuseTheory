# Muse Theory — heavier ML dependencies (Apple Silicon / arm64, Python 3.11).
# Installed on top of requirements-core.txt. Everything here is CPU/MPS-capable;
# there is no CUDA requirement anywhere in this project.

#   - torch / torchaudio: MPS-backed tensor + audio I/O, used by demucs, the

#     them and the pipeline falls back to deterministic templates.
#   - torchcrepe: optional high-accuracy pitch tracker (pYIN is the default).
